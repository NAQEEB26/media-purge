# Security Policy

## Supported versions

Security fixes are applied to the latest stable release published on [WordPress.org](https://wordpress.org/plugins/media-purge/).

| Version | Supported |
|---------|-----------|
| 1.4.x   | Yes       |
| &lt; 1.4 | No        |

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security reports.

Email the maintainer via the contact options on [getmediapurge.com](https://getmediapurge.com/) or use the WordPress.org plugin support channel privately if needed.

Include:

- A clear description of the issue
- Steps to reproduce
- Impact assessment (if known)
- Your preferred contact for follow-up

We will acknowledge reports as soon as practical and work on a fix before any public disclosure.
